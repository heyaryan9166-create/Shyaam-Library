SHRI SHYAAM LIBRARY — iPhone PWA starter

IMPORTANT: iPhone Home Screen installation requires the files to be hosted on an HTTPS website. Opening index.html directly from Files will not install it as a PWA.

FREE DEPLOYMENT OPTION:
1. Create a free GitHub account at https://github.com
2. Create a new public repository named shyaam-library
3. Upload all files in this folder to the repository root.
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for GitHub Pages to publish the HTTPS site.
6. On iPhone 13, open the published URL in Safari.
7. Tap Share > Add to Home Screen > Add.

APP FEATURES IN THIS STARTER:
- Add/edit students and assign seats (50)
- Fee plans: Day ₹500, Day-Night ₹750, Night ₹350
- Current-month payments and due calculation
- WhatsApp reminder link (you send the message)
- Print/save receipt through browser print dialog
- JSON backup and restore
- Offline cache after first successful visit

DATA / SECURITY:
- Student records are stored only in this browser on this device.
- There is no cloud sync, remote admin login, or automatic push notification in this starter.
- Export backups regularly. Avoid public/shared devices.
- Test with sample records before entering real student data.

This is a progressive web app, not an App Store native IPA.
